# 系统配置说明 | 710号汽车之家

后台入口：`系统管理` 菜单下包含 **系统参数 / 多语言配置 / 菜单可视化 / 对象存储 / 审计日志 / 用户角色**。

配置数据统一存放在 `sys_config`（KV 结构，按 `group` 分组），密钥类字段 AES 加密存储。
读取统一走 `ConfigService`（带缓存），前台通过 `/api/public/site` 获取公开配置。

---

## 一、系统参数（站点配置）

路径：后台 → 系统管理 → 系统参数。

| 分组 | 主要参数 | 说明 |
| --- | --- | --- |
| 站点 | 站点名称、Logo、ICP、备案、客服电话、营业时间 | 前台头部/底部展示 |
| SEO | 默认标题、关键词、描述 | 官网 meta |
| 公众号 | AppID、AppSecret、Token、EncodingAESKey | 见「微信对接」文档 |
| 小程序 | AppID、AppSecret | 小程序登录 |
| 微信支付 | 商户号、API 密钥、证书 | 在线结算 |
| 业务 | 预约时段、取消规则、存胎默认周期、逾期费率 | 业务参数 |

保存后经 `/api/admin/config/save-group/{group}` 实时生效（缓存同步刷新）。

## 二、多语言配置

路径：后台 → 系统管理 → 多语言配置。

- **语言列表**：新增语言（如 `ja-JP`）、启用/停用、排序、设为默认。
- **内容字段**：按「业务类型 + 业务ID + 语言」录入字段（`service / article / menu / banner / config`）。
- 详细方案见 [multi-language.md](multi-language.md)。

## 三、菜单可视化

路径：后台 → 系统管理 → 菜单可视化。

四端菜单统一维护：

| 端 | platform | 用途 |
| --- | --- | --- |
| 公众号 | `mp` | 微信自定义菜单，可一键同步 |
| PC 官网 | `public` | 顶部导航 |
| 小程序 | `miniapp` | tabBar |
| H5 | `h5` | 底部导航 |

操作：拖拽调整顺序/层级 → 属性面板编辑 → 右侧 PC/手机实时预览 → **保存并发布**。
公众号端额外提供「预览到微信」，详见 [menu.md](menu.md)。

## 五、用户角色 / 权限 / 菜单（RBAC）

路径：后台 → 系统管理。模型为标准的 **用户 → 角色 → 权限(菜单/按钮) → 菜单树**。

- **用户角色**：用户管理（账号/密码 BCrypt、门店归属、状态）「分配角色」；角色管理（角色编码、数据范围、状态）「分配权限」。
- **菜单管理**：维护后台侧边栏菜单树，支持三种类型：
  - `DIR` 目录、`MENU` 菜单（页面）、`BUTTON` 按钮（权限点）；
  - 字段含 路由地址、组件路径、**权限标识(perms)**、图标、排序、显示、状态；
  - 新增/编辑/删除（删除会级联子级并解除角色授权），图标为 Element Plus 图标名。
- **按钮级权限**：`perms` 即权限标识，例如业务按钮 `store-info:add` / `:edit` / `:delete`。
  - 前端 `CrudTable` 默认按资源名（url 去掉 `/admin/`）自动判断，`新增/编辑/删除/批量删除` 按钮按权限显示；
  - 也可在任意元素上用指令 `v-perm="'xxx:add'"` 或在逻辑里调用 `hasPerm('xxx:add')`；
  - **超级管理员默认拥有全部权限**，不受菜单授权限制；
  - 若某资源不需要控制，给 `<crud-table perm="">` 传空串即可关闭。
- **数据范围**：角色的 `dataScope`（全部/本店/本人）在后端过滤数据（技师端仅见本人工单）。
- 后端关键写接口用 `@RequiresPermission("system:menu:manage")` 等注解强校验；未授权即便伪造请求也会被拒绝。

> 提示：新资源的“按钮权限点”需要在「菜单管理」里挂到对应菜单下，并在「角色管理 → 分配权限」里勾选后，对应角色才会看到按钮。脚本 `sql/data.sql` 已内置全部业务资源的按钮权限点，并对拥有该菜单的非只读角色默认授权。

## 六、审计日志

所有标注 `@AuditLog` 的接口自动记录：操作人、模块、操作、请求方式/地址、参数、返回、IP、耗时、异常。
路径：后台 → 系统管理 → 审计日志，支持按操作人/模块/操作检索。

---

## 七、安全相关

| 能力 | 实现 |
| --- | --- |
| 防重提交 | `@RepeatSubmit` 注解 + Redis 锁 |
| 接口限流 | `@RateLimit` 注解 + Redis 计数 |
| 敏感词 | `@SensitiveWord` / `SensitiveWordUtil`，词库 `resources/sensitive-words.txt` |
| 脱敏 | 手机号/车牌 `DesensitizeUtil` 展示脱敏，存储用 AES 加密 |
| 密钥加密 | 系统参数中密钥字段 AES 加密落库 |
| 权限隔离 | 技师端仅见本人工单；门店角色按 data_scope 过滤 |
