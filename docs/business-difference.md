# 业务差异文档 | 710号汽车之家 vs 中医馆数字化平台 PRD

> 本平台整体**架构对标《中医馆数字化平台 PRD》**（前后端分离、RBAC、CMS、存储抽象、公众号、多端），
> 但业务域由「中医馆」替换为「汽车维修保养连锁」，并**新增**多语言、菜单可视化、富文本、汽修预约工单与存胎寄存等模块。
> 本文标注相对 PRD 的 **新增 / 调整 / 删减**。

## 二、新增模块

1. **多语言（i18n）**：`sys_language` + `sys_i18n_content`，前台语言切换器，双语 SEO / hreflang。
2. **菜单可视化**：`cms_menu` 覆盖公众号 / 官网 / 小程序 / H5 四端，拖拽排序 + 实时预览 + 公众号「预览到微信 / 发布」。
3. **富文本统一组件**：WangEditor 5，图片自动走对象存储，多语言 tab 分别保存，粘贴清洗。
4. **图片/附件上传组件**：独占整行卡片块、多图并行、拖拽排序、缩略图网格、批量删除、进度与重试。
5. **对象存储 5 驱动**：本地 / S3 / OSS / COS / MinIO，卡片式配置 + 连接测试 + 切换二次确认。
6. **预约 + 工单看板**：按状态分列卡片式看板、超时高亮、拖拽优先级、全流程状态机。
7. **接车技师端**：技师账号、派工、接车开单（检查项/报价/质检）、施工进度上报、用料登记（自动出库）、完工流转。
8. **存胎寄存业务模型**：寄存下单、寄存库存、入库/取胎凭证留证、到期提醒、逾期计费（汽修行业特有）。
9. **配件耗材进销存**：入库/出库/盘点、出库关联工单、库存预警、毛利统计。
10. **会员营销**：多车绑定、积分、储值、优惠券、养护套餐、充值赠礼。
11. **H5 移动端**：客户预约 + 技师移动办公，与小程序共用会员体系（UnionID）。

## 三、业务模型调整（行业专用）

| 中医馆概念 | 汽修对应模型 | 关键差异 |
| --- | --- | --- |
| 挂号 → 就诊 | 预约 → 接车开单 → 工单 | 增加**派工/工位/施工/质检/结算**多阶段状态机 |
| 医师排班 | 技师排班 + 工位占用 | 增加**同时开工上限**与派工记录 |
| 处方 / 药房 | 用料登记 / 配件库存 | 增加**出库自动扣减库存**与库存预警 |
| 疗程卡 | 养护套餐 / 储值 | 增加**多车绑定**与**存胎寄存** |
| 门店 | 连锁门店 + 工位 | 门店维度数据隔离（data_scope） |

### 工单状态机

```
待接车 → 待派工 → 施工中 → 待质检 → 待结算 → 已离店 → 已评价
                    ↘ 已取消 / 退款
```

状态流转写入 `work_order_log`，超时看板高亮。

## 六、相对 PRD 的架构一致性说明

保持与 PRD 一致的架构准则：

- 前后端分离、统一返回结构（`Result` / `PageResult`）。
- RBAC（用户-角色-菜单-权限）+ 数据范围（全部/本店/本人）。
- 审计日志、防重提交、限流、敏感词、脱敏、密钥加密。
- 多端（后台/官网/小程序/H5/技师端）共享同一后端与会员体系。
- 对象存储抽象、配置中心（KV + 缓存）、CMS 内容管理。
